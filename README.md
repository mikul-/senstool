# SensTool

Sensitivity calculator for Quake Source engine and Diabotical, plus FOV-to-sensitivity conversion.

## Features

- **Quake → Diabotical** — Convert Quake sensitivity, accel, senscap, DPI, yaw, and resolution to Diabotical settings
- **Diabotical → Quake** — Reverse: convert Diabotical settings back to Quake cfg commands
- **FOV Calculator** — Calculate sensitivity for FOV changes with monitor-distance match and aspect ratio cross-conversions (16:9 / 4:3 / 1:1)
- **cm/360** — Enter cm/360 + DPI to auto-calculate sensitivity for any game
- **Resolution DPI scaling** — Calculate DPI adjustment when changing resolution

## Setup

No build required. Open `senstool.html` in any modern web browser.

**Demo:** <https://mikul.se/senstool.html>
